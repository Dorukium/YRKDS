# ADR-0012 — D7 MGM günlük ekstrem kayıtları

- Tarih: 2026-11-22
- Durum: Kabul (kısmi)

MGM kamu ekstrem değerler sayfalarında 1969-01-17 / 331.5 mm kaydını
doğrulayacak sayfa bulunamadı (Firecrawl araması boş döndü). 331.5 mm değeri
yalnızca proje veri seti 3.13'te yer alır ve kaynak etiketi "proje veri seti"
olarak korunur; resmi MGM doğrulaması iddia edilmez. Yetkinlik rozeti: Proxy.
