# ADR-0006 — NASA Global Landslide Susceptibility

- Tarih: 2026-11-22
- Durum: Kabul

NASA GES DISC üzerinden alınacak Global Landslide Susceptibility verisi için
erişim kimlik bilgisi/lisans onayı bu ortamda doğrulanamadı. H bileşeni için
birincil kaynak (DEM eğimi + MTA heyelan envanteri) korunur; NASA verisi
**proxy olarak üretilmez**. docs/capraz_kontrol.md'de "yok" etiketli.
